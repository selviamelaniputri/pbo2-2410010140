
# P07 – Mini Proyek Katalog Buku Perpustakaan

## Deskripsi Proyek
Katalog Buku Perpustakaan merupakan aplikasi desktop berbasis Java Swing yang digunakan untuk mengelola data buku perpustakaan. Aplikasi ini menyediakan fitur tambah, ubah, hapus, pencarian, dan pengelolaan status ketersediaan buku.

## Fitur Aplikasi
1. Menampilkan daftar buku menggunakan JTable.
2. Menggunakan AbstractTableModel untuk mengelola data tabel.
3. Menampilkan minimal 5 data buku.
4. Menambahkan buku melalui JDialog.
5. Mengubah data buku yang dipilih.
6. Menghapus buku dengan dialog konfirmasi.
7. Memvalidasi kode dan judul buku.
8. Memvalidasi tahun terbit berupa angka dari 1900 sampai tahun berjalan.
9. Mencari buku berdasarkan kode, judul, atau penulis.
10. Mengurutkan data buku melalui tabel.
11. Menampilkan jumlah buku dan jumlah buku yang tersedia.
12. Menyediakan menu File dan Buku beserta pintasan keyboard.

## Teknologi yang Digunakan
